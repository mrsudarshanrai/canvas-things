## The Collection

Each project in this repository is a standalone experiment focusing on math, physics, and interactive logic.

| Project Name             | Description                                                     |                Source                 |
| :----------------------- | :-------------------------------------------------------------- | :-----------------------------------: |
| **Archery**              | A physics-based bow and arrow simulation with trajectory logic. |          [source](./archery)          |
| **Connecting Particles** | Interactive network mesh that reacts to mouse proximity.        | [source](./connecting-line-particles) |
| **Particles 01**         | High-performance particle emitter system.                       |       [source](./particles-01)        |
| **Captcha Gen**          | Procedural security image generation using Canvas noise.        |     [source](./captcha-generator)     |
